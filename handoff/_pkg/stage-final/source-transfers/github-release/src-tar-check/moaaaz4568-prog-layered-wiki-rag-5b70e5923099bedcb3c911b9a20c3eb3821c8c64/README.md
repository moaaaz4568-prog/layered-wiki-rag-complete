# layered-wiki-rag

مستودع خاص لمخرجات تصميم نظام الويكي الطبقية مع RAG.

## المحتويات

- `promptastra6fgss.md`: البريف الأصلي.
- `layered-wiki-rag-design.md`: المواصفة المعمارية العربية الكاملة.
- `layered-wiki-rag-guide.html`: صفحة القراءة الشخصية RTL وتعمل دون اتصال.
- `AGENTS.md`: قواعد تشغيل آمنة بلا أسرار.
- `CHECKSUMS.sha256`: بصمات الملفات المرفوعة.

## الحالة

هذه الملفات توثق التصميم وخطة القياس. لم يُشغّل محرك ingest أو الفهارس أو تجارب v0.1؛ الحالات غير المنفذة موسومة داخل الوثيقة. رابط TransferNow المذكور في البريف أعاد `Transfer not found` عند الفحص.

## سياسة الأسرار

لا تُحفظ رموز GitHub أو كلمات المرور أو مفاتيح API أو السجلات أو ملفات البيئة في هذا المستودع. أي رفع لاحق يحتاج طلباً صريحاً ويستخدم اعتماداً مؤقتاً من مدير أسرار أو متغير بيئة.
