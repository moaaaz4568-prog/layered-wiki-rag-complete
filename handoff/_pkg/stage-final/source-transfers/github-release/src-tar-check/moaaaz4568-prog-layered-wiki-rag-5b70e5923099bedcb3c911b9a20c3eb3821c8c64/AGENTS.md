# AGENTS.md

## نطاق المستودع

هذا مستودع خاص لوثائق تصميم `layered-wiki-rag` ومصادرها.

## قواعد العمل

- حافظ على المصدر الأصلي ومخرجات التصميم، ولا تعدّل المصدر بصمت.
- ميّز بين `OBSERVED` و`REPORTED` و`PROPOSED` و`UNKNOWN` و`NOT_RUN`.
- لا تضف نتيجة قياس أو نجاح اختبار دون أمر ومخرج قابلين للفحص.
- اربط الادعاءات المشتقة بمصدرها ومحدد موضعها عندما تتوفر البنية التشغيلية.
- لا تنشئ Master قبل اكتمال مصطلحات مجلده في التصميم المستهدف.
- لا تحذف الملفات الأصلية بسبب اختلاف أو تعارض؛ سجّل القرار والحالة.
- راجع `REJECTED` قبل إعادة اقتراح بديل سبق رفضه.
- ارفع ملفات هذا المستودع إلى GitHub فقط عند طلب المستخدم صراحة، وبعد فحص الأسرار.

## حماية الاعتمادات

- ممنوع تخزين Personal Access Tokens أو كلمات المرور أو مفاتيح API في هذا الملف أو أي ملف آخر.
- لا تضع الاعتماد في remote URL دائم أو سجل تشغيل.
- استخدم مدير اعتماد أو متغير بيئة مؤقتاً، ثم دوّر الرمز إذا ظهر في محادثة أو سجل.
- لا ترفع سجلات النظام أو ملفات البيئة أو الملفات غير المرتبطة بالمهمة دون مراجعة.
