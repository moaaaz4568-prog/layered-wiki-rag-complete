# الماسترز — masters/README

> **المرجع:** analysis-wiki-talk-01.md §1.8.3 وقرار «مصطلحات أولاً» في repo-plan-01.md §3.3

## التعريف

الماستر = ملف يقرأه النموذج مرة واحدة فيصبح خبيرًا في مجلد كامل. لا يُنشأ قبل اكتمال مصطلحات مجلده الرئيسي.

## خطوات التوليد

1. تُجمع المصطلحات كاملة من الخام (مصطلح = اسم + تعريف + مصدر).
2. تُبنى مصطلحات المجلد الفرعي.
3. يُكتب الماستر الرئيسي + فرعيات بالإحالة.

## القاعدة التي لا تُكسر

- لا ماستر قبل اكتمال مصطلحات المجلد — حتى لو ضربت المساندة أو بادرات المحتوى.
- الخرق المرصود: 27,742 ذرة مصطلح مقابل 5 ماسترز فقط في wikillm = ماستر قبل مصطلح. هذه هي الحالة الاحترازية التي تمنع تكرارها هنا.
- أي ماستر لاحق يُدرج ضمن checklist.md قبل أي اعتماد.

## الحالة الآن

- لا ماسترز نشطة بمحتوى مثبت في v0.1؛ المجلد الحالي توثيق طريقة التوليد فقط.
- لا توليد جماعي ولا مستودعًا بنشأ قبل التشغيل البشري.
