# الماسترز — الفهرس الجامع وقواعد التوليد

> **وسوم الدليل:** [OBSERVED] = مقاس/مقروء مباشرة · [REPORTED] = منقول · [PROPOSED] = مستقبلي غير منفَّذ · [UNKNOWN] = لا دليل · [NOT_RUN] = لم يُشغَّل بعد. [REPORTED: repo-plan-01.md §1.2.3]

## 1. ما هو الماستر؟

الماستر ملف يقرأه النموذج مرة واحدة فيصبح خبيرًا في مجال محدد — [REPORTED: analysis §4.3: «يقرأه النموذج مرة واحدة فيصبح خبيراً» + البريف الأصلي §1.1: «عقول متخصصة»].

## 2. قاعدة التوليد (مصطلحات قبل الماستر)

1. **القاعدة الحاكمة:** مصطلحات أولاً، وماستر فقط بعد اكتمال مصطلحات المجلد الرئيسي — [REPORTED: analysis §1.8.3].
2. **نقل لا حذف:** مسار المصطلحات r → done → processed — [REPORTED: analysis §1.8.3].
3. **التعريف العملي من الشجرة:** `terms/` يسبق `masters/` في أي مجلد شخصية، والماستر يُبنى من المصطلحات المكتملة للمجلد فقط — [REPORTED: analysis §4.3].
4. **الماستر الرئيسي والمتخصص:** يُبنى ماستر الرئيسي ثم ماسترز فرعية بالإحالة إلى الرئيسي — [PROPOSED: design §2.9 «الماستر الرئيسي والمتخصص: قاعدة البناء» + repo-plan §3.1].
5. **بوابة الاعتماد:** كل ماستر يمر بمراجعة بشرية قبل اعتماده canon — [REPORTED: analysis §4.3 `masters/review/checklist.md` + §1.8.9].

1. قائمة مراجعة بشرية (`masters/review/checklist.md`) — موجودة في repo/ وتضم 10 نقاط اعتماد [OBSERVED 2026-11-05 — `grep -c '^- \[ \]'` = 10]: مراجعة بشرية كاملة خصوصًا الصفحات الحساسة دينيًا/علميًا؛ إثبات حي بفحص القرص بعد التوليد لا ادعاء الوكلاء وحده؛ كل إجابة باستشهاد بمقطع خام بلا استثناء؛ الخامة (Raw) لم تُمس قراءة فقط؛ الاستشهادات (مسار + عنوان مقطع + معرّف) موجودة وصالحة؛ لا تناقض ميكانيكي (رقم/تاريخ) لم يُحكم بشريًا؛ المصطلحات مكتملة في المجلد الفرعي قبل الاعتماد؛ commit صغير منطقي وCHANGELOG آخر؛ لا أسرار (grep §5.2 في repo-plan-01)؛ الاعتماد نفسه موسوم OBSERVED بالأمر والمسار — والترقية لـ Canon بموافقة إنسان فقط [OBSERVED: قراءة masters/review/checklist.md مباشرة].
