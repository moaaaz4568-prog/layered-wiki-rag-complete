# 🏛️ مستودع محادثات وسجلات Antigravity (AGY) — الأرشيف الموحد

## 1. نظرة عامة (Overview)
يحتوي هذا المستودع على الأرشيف المنظم لمحادثات وسجلات بيئة **Antigravity CLI (AGY)** المرتبطة بمشروع **الويكي الإدراكي (Cognitive Wiki OS)** ومسار أرجون (`wikillm/argon_version/wiki_ver2`).

تم استخراج وتصنيف البيانات وفقاً لـ **استراتيجية الطبقات الثلاث (Three-Tier Strategy)** دون حذف أي سجل، وبما يحفظ 100% من الذكاء الفكري والقرارات الهندسية.

---

## 2. بنية المجلد (Directory Structure)


## 3. محتويات المجلدات بالتفصيل

### 🔹 `core_wiki_sessions/` (النواة التأسيسية الصافية)
تحتوي على ملفات قواعد بيانات SQLite الأصلية بصيغة `.db` للجلسات العشرين التأسيسية التي بنت:
- نظام تشغيل الويكي الإدراكي (`Cognitive Wiki OS`).
- وثائق وأنظمة البناء `SYS_01` حتى `SYS_10`.
- قوالب النطاقات والمولدات الآلية.
- تدقيق ومراجعة أنظمة أرجون.
تم نسخها بنمط القراءة الحصرية وحفظ حالتها البايتية الأصلية.

### 🔹 `brain_logs/` (سجلات العقل الإدراكي)
المجلدات المقابلة للجلسات العشرين من مسار `~/.gemini/antigravity-cli/brain/`:
- تتضمن سجلات الأحداث الكاملة `transcript.jsonl` و `transcript_full.jsonl`.
- تتضمن ملفات الأثر والخطط وخرائط التحليل (`Artifacts`) وسكريبتات الفحص الميداني (`scratch/`).

### 🔹 `tier1_strong/` (المستخلص النصي المركز)
ملفات JSONL صافية تحتوي على تسلسل الحوار والتوجيهات (User Prompts + Model Responses + Thinking) لكل الجلسات القوية (المطابقات ≥ 5)، مفهرسة بمعرف الجلسة `{conversation_id}.jsonl`. تم تجريدها من مخلفات استدعاء الأدوات الثقيلة لتوفير وصول لحظي للمحتوى الفكري.

### 🔹 `index.csv` (الفهرس الشامل)
جدول تفصيلي يضم 178 جلسة تم مسحها، ويتضمن:
1. الترتيب حسب الكثافة.
2. معرّف الجلسة (`conversation_id`).
3. تاريخ التعديل (UTC).
4. العنوان ومسار مساحة العمل.
5. عدد مطابقات كلمات الويكي وكلمات النواة.
6. أحجام قواعد البيانات وسجلات الـ Brain بالبايت والميغابايت.
7. تصنيف الجلسة (نواة / قوية).

## 4. الإحصائيات البايتية
- **إجمالي الجلسات المفهرسة:** 178 جلسة مطابقة.
- **جلسات النواة التأسيسية (Core):** 20 جلسة (بحجم إجمالي ~35 MB).
- **الجلسات القوية (Tier 1 Strong):** 176 جلسة مستخلصة كـ JSONL.
- **التوافق:** التزام صارم بقاعدة (Zero Deletion) وقراءة SQLite الآمنة (`mode=ro`).
