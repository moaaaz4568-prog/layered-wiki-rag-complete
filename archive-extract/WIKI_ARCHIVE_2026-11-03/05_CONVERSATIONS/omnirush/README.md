# 🚀 مستودع محادثات وسجلات OmniRush — الأرشيف الموحد

## 1. نظرة عامة (Overview)
يضم هذا المستودع كافة سجلات ومحادثات بيئة **OmniRush** المتعلقة بمشروع **الويكي الإدراكي (Cognitive Wiki)**، وتطوير وتدقيق ملفات `NEXUS_LLM_WIKI`، وبناء الـ chunks، ونظام `wikillm`.

تم استخلاص المحادثات من 3 مصادر رئيسية:
1. ملفات الجلسات الموضوعية من `~/.omnirush/agent/sessions/`.
2. قاعدة البيانات النشطة `~/.local/share/omnirush/opencode.db`.
3. قاعدة البيانات الاحتياطية الميدانية `/root/r/BACKUP_OMINIRUSH_CHAT/opencode.db`.

## 3. تفاصيل الأقسام ومحتوياتها

### 🔹 `topic_sessions/` (الجلسات الموضوعية الكبرى)
- تم اختيار **49 ملف جلسة خام** (JSONL) تمثل قمة التفاعل حول مفاهيم الويكي، هندسة الذاكرة، مراجعة النماذج، وبناء الحزم المعرفية.
- الحجم الإجمالي: **44.00 MB** (ممتثلاً بدقة لسقف الـ 45 MB المحدد).
- تتضمن جلسات استكشاف المراجع (`ses_f26ced106ffeMk7sCCNf8dpMea`)، تقرير التدقيق الدلالي (`ses_ee842461fffe2k1cJMbYXSHjU2`)، مسودات أرجون والـ chunk builders.

### 🔹 `db_extracted/` (المستخلص النصي الصافي)
- نظراً لأن قواعد بيانات SQLite كاملة (`opencode.db`) تفوق 446 MB و105 MB وتحتوي على فهارس وأحداث غير نصية، تم تطبيق **استراتيجية الاستخراج المستهدف (Targeted Extraction)**.
- **`active/`:** يتضمن **160 ملف JSONL** تمثل 160 جلسة نشطة استُخلصت منها نصوص الويكي المطابقة (بما فيها جلسة `wikillm` الفريدة `ses_e81921099ffebArD7mwDNRJZnB`).
- **`backup/`:** يتضمن **34 ملف JSONL** تمثل الجلسات التاريخية الاحتياطية المستخرجة من نسخة أكتوبر 2026.
- كل سطر JSONL يحوي المعرف، الطابع الزمني، نوع النص، والنص الكامل.

### 🔹 `index.csv` (الفهرس الموحد)
- فهرس مرجعي موحد يربط كافة الجلسات:
  - معرّف الجلسة (`session_id`).
  - المصدر (`agent/sessions` أو `active_opencode_db` أو `backup_opencode_db`).
  - الحالة (`COPIED_TO_TOPIC` أو `DB_EXTRACTED_ACTIVE` أو `DB_EXTRACTED_BACKUP` أو `INDEXED_ONLY`).
  - عدد المطابقات والحجم وتاريخ الجلسة والعنوان.

- **ملفات الجلسات الخام المؤرشفة:** 49 ملفاً (44.00 MB).
