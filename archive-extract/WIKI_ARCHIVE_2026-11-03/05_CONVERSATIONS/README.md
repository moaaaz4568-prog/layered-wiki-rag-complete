## 1. الفلسفة والقواعد الصارمة المطبقة
1. **استخراج لا نسخ قواعد بيانات (No DB copying):** حُظِر نسخ ملفات SQLite الكبيرة (`opencode.db` > 1 GB) لحماية بطاقة التخزين. تم الاستخراج برمجياً عبر `mode=ro` إلى ملفات JSONL مستقلة لكل جلسة.
2. **صفر حذف (Zero Deletion):** لم يُحذف أي ملف أو مجلد من البيئة أو المصادر.
3. **أعلى درجات الولاء للبنية:** كل جلسة خُزنت بصيغة JSONL الأصلية لحفظ كافة خصائص الأدوات والمحادثات.
