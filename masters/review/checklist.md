# قائمة مراجعة بشرية قبل الاعتماد — masters/review/checklist

> **الدليل:** PROPOSED (بوابة مقترحة) — العمل الفعلي للماسترز لاحقًا بوسم OBSERVED فقط
> **القاعدة:** الترقية لـ Canon بموافقة إنسان فقط؛ الوكيل لا يرقّي شغله

## نقاط الاعتماد

- [ ] مراجعة بشرية كاملة لمحتوى الماستر — خصوصًا الصفحات الحساسة دينيًا / علميًا
- [ ] إثبات حي: فحص القرص بعد التوليد، لا ادعاء نجاح من الوكلاء وحده
- [ ] كل إجابة باستشهاد بمقطع خام — لا استثناء
- [ ] الخامة (Raw) لم تُمس — القراءة فقط
- [ ] الاستشهادات: المسار + عنوان المقطع + معرّف المقطع موجودة وصالحة
- [ ] لا تناقض ميكانيكي (رقم/تاريخ) لم يُحكم بشريًا
- [ ] المصطلحات اكتملت في المجلد الفرعي قبل الاعتماد
- [ ] commit صغير منطقي وCHANGELOG آخر
- [ ] لا أسرار (grep §5.2 في repo-plan-01)
- [ ] الاعتماد نفسه مُوسوم OBSERVED بالأمر والمسار

## قرار الإنسان

- APPROVED / REJECTED (يُدخل يدويًا)

> لا يُكتب APPROVED إلا بيد إنسان. الوكيل لا يوقع الاعتماد.
